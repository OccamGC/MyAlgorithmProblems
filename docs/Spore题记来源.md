# Spore 题记来源 / Sources for Spore epigraphs

Grox 系列与 Spode 经学院的英文题记采用游戏文字的公开转录。中文题记保留其中文措辞；两种语言的用词不一定逐字对应。

The English epigraphs in the Grox series and Spode Seminary use public transcriptions of the game text. The Chinese and English wording need not correspond word for word.
