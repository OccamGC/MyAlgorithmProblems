# 翻新题目状态分类（草案 v0.1）

每道翻新后的题目恰有一个主分类。分类描述**材料齐备程度与检验结果**，不改变按主题组织的目录位置；发现的问题和缺失项另行记录。原仓库只作为参考，不按这些状态改动。

| 编号 | 分类 | 判定标准 |
| --- | --- | --- |
| 1 | 完整，但尚未检验正确性 | 新版题面、题解、参考程序、生成器和生成计划、必要的样例与评测源码均已备齐，但尚未完成规定的正确性检验。 |
| 2 | 经检验通过 | 材料齐备，按工作流完成题意、双语一致性、程序、数据、边界和评测方式等检验，未留下影响使用的已知问题。 |
| 3 | 经检验发现有问题 | 材料齐备，检验发现题意、题解、程序、数据、样例、评测方式或性能约束存在尚未修复的问题。记录复现方法和影响。 |
| 4 | 组成不完整 | 题面基本写完，但缺少必要组成部分，例如中英题解、标准程序、数据生成器、生成计划、样例或需要的特殊评测源码。逐项列出缺失内容。 |
| 5 | 严重不完整 | 题面本身尚未写完，题意、输入输出或关键规则无法明确确定；其他材料是否存在不影响此分类。记录已知部分与待定问题。 |

## 判定顺序

1. 题面未写完、无法确定完整规则时归 **5**。
2. 题面基本完整，但必要材料缺失时归 **4**。若同时发现错误，在问题清单中记录；补齐材料后若错误仍在，转为 **3**。
3. 材料齐备后，尚未完成检验时归 **1**。
4. 完成检验后，有未修复问题归 **3**；全部通过归 **2**。

修复问题后不能直接把 **3** 改为 **2**；先记录修复内容，重新运行受影响的检验，再更新分类。补齐 **4** 或 **5** 的材料后也先进入 **1**，经过检验才能进入 **2**。已通过的题目若发现新问题，立即改为 **3** 并附证据。

分类数字只是编号，不代表题目质量评分或优先级。题目的主题目录保持不变，方便按主题阅读；状态可在单题内部记录和后续的题目索引中展示。题目索引的具体文件格式待确定。
