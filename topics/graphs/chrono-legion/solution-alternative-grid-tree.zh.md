# 超时空军团 · 二维线段树

Codex（GPT-6）编写的 [C++17 实现](alternative-grid-tree.cpp)用格点树同时维护建筑数与最大建造时间。二分从半径零开始，同格建筑分别计数。建图后沿用主解的合数模行列式。

计数随半径单调，最小可行半径确定后必须在整个闭正方形内查询时间最大者。网格预处理 $O(NM)$，每项需求需 $O(\log(\max(N,M)+1)\log(N+1)\log(M+1))$ 时间，另加主解中的行列式计算。建图存储 $O(NM+K^2+S)$，其中 $S$ 为需求总数。
