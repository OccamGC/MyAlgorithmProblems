# 转动的字节 · 最短路分阶段

Codex（GPT-6）编写的 [C++17 实现](alternative-shortest-dag.cpp)先从终点逆向跑 Dijkstra，保留使距离等式取等的边。每个最短路上的标签块都有唯一的字符串起始位置，因此从候选起点同步前进时可逐字符只保留最小位，并对块去重。然后只沿着与所得字符串相符的边标记可达点。从终点反向每步挑编号最小的可达前驱，便满足第三层的逆序比较。使用可重复入堆的二叉堆，时间 $O((n+m)\log(n+m+1)+L)$，空间 $O(n+m+L)$。
