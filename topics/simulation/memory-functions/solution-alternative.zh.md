# 连续内存中的字符串函数 — 补充解法

**出题人解法；Codex（GPT-6）整理实现。** 这份方案保留连续字节数组与前缀和定位，用扫描寻找结束零，用逐字节赋值执行修改。

错误检查与警告顺序见[主解法](solution.zh.md)：完整检查后才修改，包括结束字节的复制区间不能重叠。扫描首个零得到准确的串长；数组中的字符串一定是一段一后跟零，因此写入同样的值序列即为正确复制。每次操作前后数组逐字节等于题目中的内存，归纳可证全部输出正确。

建立前缀和与内存需 $O(n+S)$ 时间，单次操作最坏 $O(S)$ ，总时间 $O(n+S+kS)$ ，空间 $O(n+S)$ .实现较直接且数组存储常数小；查询密集时，线段树的渐进复杂度更好。这份[程序](alternative.cpp)在当前完整数据和预估时限内通过，可作为并列的简洁实现。
