# 字符 X：逐格判断斜带

出题人解法：逐格判断两条斜带；固定模板替换也见于配套程序。Codex（GPT-6）：整理标准 C++17 实现，明确输出尺寸并验证空格。

## 算法与证明

枚举行 $i=1,\ldots,8$ 和列 $j=1,\ldots,10$ .若 $j\in[i,i+2]$ 或 $j\in[9-i,11-i]$ ，输出指定字符，否则输出一个空格。每行结束输出换行。

这两个闭区间正是题目规定的两条斜带。逻辑“或”实现它们的并集，交叠格不会重复输出；其余格均为空格。按行、列递增输出恰好覆盖全部格子，因此图案和顺序正确。

## 复杂度与实现

每个图案输出固定的 $80$ 个格子和 $8$ 个换行。总时间 $O(T+1)$ ，额外空间 $O(1)$ .两条条件分别加括号，避免混淆逻辑与、或的结合顺序。

行尾空格也是矩形的一部分，不应删去。不要在两组图案之间额外打印空行。$T=0$ 时循环不执行，输出为空。

[std.cpp](std.cpp) 直接对应几何定义，作为首选。[固定模板替换](solution-alternative.zh.md)及 [alternative.cpp](alternative.cpp)是出题人提供的另一种表达：省去逐格推导，但仅适合尺寸和形状固定的情形。两份程序均通过完整正式数据；本机耗时主要包含启动及输出开销。
