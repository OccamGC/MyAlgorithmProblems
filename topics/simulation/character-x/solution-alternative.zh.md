# 字符 X：固定模板替换

出题人解法。Codex（GPT-6）：保留固定模板思路并核对行尾空格。程序为 [alternative.cpp](alternative.cpp)，与[逐格判定](solution.zh.md)同阶，作为补充方案通过完整正式数据。

用八个长度为十的字符串保存图案：需要输出字符的位置记为 `#` ，其他位置保存实际空格。依次扫描每行，将 `#` 替换为输入字符，空格照常输出，最后换行。

模板的每一行与两条斜带的并集逐格对应。替换只改变填充字符，不改变格子位置或行列数量，因此对所有允许的字母和数字都产生正确结果。模板中的 `#` 是内部标记，不会被原样输出。

时间为 $O(T+1)$ ，额外空间为 $O(1)$ ，其中保存了固定的 $80$ 个格子。该方法便于展示固定图案；若行列数或斜带宽度可变，逐格条件更容易适配。检查必须比较完整行，不能先去除空格再比对。

测试配方见 [plan.json](tests/plan.json)，生成方式见[数据生成说明](../../../README.md#使用题目文件)。参考环境、逐次测量和适用范围见[评测说明](../../../docs/评测环境与性能.md)。
