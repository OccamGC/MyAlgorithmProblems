# 动态目录树 · 相邻点对 LCA

Codex（GPT-6）编写的 [C++17 实现](alternative-pair-lca.cpp)比较暴露根路径的结点数，原树深度为 $d$ 的点在扩展树上恰有 $2d+1$ 个路径结点，负边权也不会改变选择。 暴露两个端点间的路径也能检验邻接：扩展路径恰有三个结点时，中间结点就是待修改的边，无需维护端点映射。

全部询问点的公共祖先为 $c$ 时，相邻点对至少有一对的 LCA 是 $c$，其余均位于 $c$ 的子树。故取最浅者。总询问点数 $K$ 下，总摊还时间 $O((n+m+K)\log(n+1))$，空间 $O(n)$。
