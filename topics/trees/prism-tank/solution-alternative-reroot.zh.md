# 光棱坦克 · 换根 DP

Codex（GPT-6）编写的 [C++17 实现](alternative-reroot.cpp)把 $u$ 发往邻点 $v$ 的值定义为从 $v$ 命中 $u$ 后，$u$ 这一侧的最优期望伤害。该量只依赖其余邻点发来的值，后序、前序两遍分别求出两个方向。在每个点使用全部入边值即可评价以它为根的答案。

不能阻断时，只需从总和扣去被排除项，再按其余项数算系数，整片森林耗时 $O(n)$。允许阻断时，设降序入边值为 $x_0,\ldots,x_{d-1}$，$S_k$ 为前 $k$ 项和，$c_k=p+(1-p)/k$。排除第 $j$ 项后，选 $k\le j$ 个邻点的最优贡献为 $c_k S_k$，用前缀最大值维护（包括选零项）。若 $k>j$，贡献为 $c_k(S_{k+1}-x_j)$。从右向左枚举 $j$，每步只新增一条直线 $y=c_k z+c_k S_{k+1}$，在 $z=-x_j$ 处查最大值。斜率按插入顺序非降，用上凸壳删除交点次序颠倒的中间线，并二分查询。相同斜率仅保留截距较大者。因此可阻断时总时间 $O(n\log(n+1))$，空间 $O(n)$。

在正式输入 `maximum-random` 上，三次运行的中位耗时为 0.0277 秒，标程为 0.0871 秒；单独测得的进程峰值工作集分别为 5.02 和 5.38 MiB。[测量条件和原始数据](../../../docs/benchmark-editorial-alternatives.json)
