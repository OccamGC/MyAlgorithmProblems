# 旋涡数

预估时间限制：0.5 秒。内存限制：256 MB。

实际时限以标准程序在目标评测环境的最慢用例中位时间乘以 $2$ ，按 $0.5$ 秒向上取整。参考环境见[评测说明](../../../docs/评测环境与性能.md)。

## 背景故事

读过伊藤润二的《旋涡》系列漫画后，你大受震撼。不过，旋涡有些复杂，二维及以上的空间也有些复杂，于是你决定先定义一种“旋涡数”，再判断一个非负整数是否属于它。

你的定义很简单：把非负整数写成不含多余前导零的十进制形式，如果从两端向中间看，对应位置的数字始终相同，就称它为旋涡数。

## 形式化问题描述

给定若干非负整数。忽略输入中的前导零后，判断每个整数的十进制表示是否从左到右、从右到左完全相同。零的十进制表示是 `0` ，因此零是旋涡数。

## 输入格式

第一行一个整数 $T$ .接下来 $T$ 行，每行一个只含数字的字符串，表示非负整数 $X$ ；字符串可以含前导零。

## 输出格式

对每个整数输出一行。是旋涡数时输出 `Y` ，否则输出 `N` .大小写必须一致。

## 样例

### 样例 1

### 输入

```text
10
1453
1026
1212
114514
666
1919810
12345678987654321
123456789987654321
11011
010
```

### 输出

```text
N
N
N
N
Y
N
Y
Y
Y
N
```

### 样例 2

### 输入

```text
7
0
000000000000000000
00100
00121
0007
999999999999999999
100000000000000000
```

### 输出

```text
Y
Y
N
Y
Y
Y
N
```

## 样例解释

样例 1 中，`1212` 不是旋涡数；`010` 表示十，因此不是旋涡数。样例 2 中，全部为零的字符串表示零，`00121` 表示旋涡数一百二十一。

## 数据范围与保证

对 100% 的数据：$1\le T\le1000$ ，$0\le X<10^{18}$ .每个输入字符串长度在 $1$ 到 $18$ 之间，且只含数字。长度限制包含前导零。
