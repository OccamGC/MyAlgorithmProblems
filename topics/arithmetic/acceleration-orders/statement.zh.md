# 星际订单：加速度

预估时间限制：0.5 秒。内存限制：128 MB。

实际时限以标准程序在目标评测环境的最慢用例中位时间乘以 $2$ ，按 $0.5$ 秒向上取整。参考环境见[评测说明](../../../docs/评测环境与性能.md)。

## 背景故事

一家星际计算中心收到了一批运动计算订单。委托方为每个模型提供两个整数参数，要求计算中心给出统一格式的距离结果。

## 形式化问题描述

每组订单给出整数 $a,t$ ，计算

$$d=\left|\frac{at^2}{2}\right|$$

这里 $a$ 是加速度参数，$t$ 是时间参数。两者都可以为负；答案严格按上述公式定义，是非负数。

## 输入格式

第一行一个整数 $T$ ，表示订单数。接下来 $T$ 行，每行两个整数 $a,t$ .

## 输出格式

输出 $T$ 行，每行一个距离 $d$ ，恰好保留一位小数。$T=0$ 时输出为空。

## 样例

### 样例 1

### 输入

```text
6
0 0
1 1
-1 1
2 -3
-3 -3
10000 10000
```

### 输出

```text
0.0
0.5
0.5
9.0
13.5
500000000000.0
```

### 样例 2

### 输入

```text
4
-10000 -10000
9999 9999
1 -10000
-10000 0
```

### 输出

```text
500000000000.0
499850014999.5
50000000.0
0.0
```

### 样例 3

### 输入

```text
0
```

### 输出

```text

```

## 样例解释

样例 1 中，前三个答案分别为 $0.0,0.5,0.5$ . 当 $a=-3,t=-3$ 时，$d=13.5$ . 最后一组得到 $500000000000.0$ . 样例 3 没有订单，因此没有输出。

## 数据范围与保证

对 100% 的数据：$0\le T\le10^4$ ，$|a|,|t|\le10^4$ .

| 分值比例 | 额外条件 |
| --- | --- |
| 100% | 无额外条件 |
