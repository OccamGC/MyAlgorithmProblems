## 形式化问题描述

给定非负整数 $n,k$ ，令 $P=1005060097$ .定义

$$a_i=i^k\binom ni\qquad(0\le i\le n)$$

本题约定 $0^0=0$ ；其他整数的零次幂为 $1$ .计算

$$S=\left(\sum_{i=0}^n a_i\right)\bmod P$$

输出最小非负余数。

## 输入格式

一行两个整数 $n,k$ .

## 输出格式

输出一行一个整数 $S$ .

## 样例

### 样例 1

### 输入

```text
10 103
```

### 输出

```text
14606983
```

### 样例 2

### 输入

```text
10 0
```

### 输出

```text
1023
```

### 样例 3

### 输入

```text
0 0
```

### 输出

```text
0
```

## 样例解释

样例二中答案为 $2^{10}-1=1023$ .样例三中，唯一项为 $0^0\binom00=0$ .

对 **100% 数据**：

$0\le n\le10^9$ ；$0\le k\le100000$ .
