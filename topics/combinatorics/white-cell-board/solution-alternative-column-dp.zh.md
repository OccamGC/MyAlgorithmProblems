# 没有全黑直线的棋盘 · 列覆盖 DP 离线计算器

Codex（GPT-6）编写的 [C++17 实现](alternative-column-dp.cpp)按格分解行转移。允许置白时，已覆盖列可放黑或白，未覆盖列置白则转入覆盖态。该行结束后逐态减去全黑这一种原地选择。分别强制零条、一条、两条对角线全黑，再按 $1,-2,1$ 容斥。单个阶数从 $O(n3^n)$ 降到 $O(n^2 2^n)$ 时间，仍需 $O(2^n)$ 空间；最大阶数的两张状态表合计 8 MiB，适合在评测内存限制之外重建整张答案表。

$n=0$ 按题意单独输出一。正阶从所有列均未覆盖开始，仅取末行之后所有列均已覆盖的状态。
