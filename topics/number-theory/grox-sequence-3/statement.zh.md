这一次，Grox 会多次给出参数，请你计算对应的结果。

## 形式化问题描述

给定非负整数 $n$ 和 $q$ 次询问。每次给出非负整数 $a,b$ ，计算

$$G(a,b)=\sum_{i=a}^{\min(n,n+a-b)}(i+b-a)!\prod_{k=a}^{i}k\pmod{921260340}$$

若求和上界小于下界，空和等于 $0$ .$0!=1$ .乘积的两个端点均包含；特别地，$a=0$ 时每个存在的乘积均含因子 $0$ .

输出答案在 $0$ 到 $921260339$ 之间的代表元。

## 输入格式

第一行两个整数 $n,q$ .接下来 $q$ 行，每行两个整数 $a,b$ .

## 输出格式

输出 $q$ 行，每行一个询问的答案。

## 样例 1

### 输入

```text
5 5
1 2
3 4
1 1
3 1
5 5
```

### 输出

```text
3038
1512
15017
387
600
```

## 样例 2

### 输入

```text
0 3
0 0
1 0
0 1
```

### 输出

```text
0
0
0
```

## 样例 3

### 输入

```text
3 4
1 0
0 1
4 1
2 2
```

### 输出

```text
15
0
0
40
```

## 样例解释

样例一的最后一问只有一项，$G(5,5)=5!\cdot5=600$ .样例二中，第一问的乘积为零，其余两问为空和。

$0\le n,a,b\le5000$ ；$1\le q\le200000$ .不保证 $a,b\le n$ .
