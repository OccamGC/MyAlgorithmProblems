# Grox的序列三 · 离线对角线递推

Codex（GPT-6）编写的 [C++17 实现](alternative-diagonal-dp.cpp)从定义的每一项提出第一个因子 $a$，得到 $F(a,b)=a(b!+F(a+1,b+1))\bmod P$。任一坐标超过 $n$ 时和为空。后继保持 $d=b-a$ 不变，所以先按 $d$ 收集询问，只对用到的对角线从右下向左上计算，再按原序输出。每个合法数对至多算一次，时间 $O((n+1)^2+q)$，空间 $O(n+q)$。与分块法相比，大批询问省去逐块查询，但需先读完全部询问。

在正式输入 `05` 上，三次运行的中位耗时为 0.1660 秒，标程为 0.2560 秒；单独测得的进程峰值工作集分别为 9.23 和 7.97 MiB。[测量条件和原始数据](../../../docs/benchmark-editorial-alternatives.json)
