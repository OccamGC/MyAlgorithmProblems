# 农务署

- 参考时间限制：0.5 秒（参考环境：[评测环境与性能](../../../docs/评测环境与性能.md)；仅供预估）
- 实际时间限制：标准程序在目标评测环境中处理最慢正式测试文件的基准时间的 2 倍，按 0.5 秒的倍数向上取整；若平台仅支持更粗的粒度，再向上取整到平台可设置值。
- 内存限制：512 MB

## 背景故事

晴川镇的农务署公布了几种作物在总产量中所占的比例，却没有公布各自产量。村长想根据这些精确比例，推算总产量至少是多少。所有产量都按整数份计，公告也可能没有列出全部作物。

## 形式化问题描述

给定 $n$ 个精确比例 $r_i$ ，满足 $0\le r_i\le1$ 且 $0<\sum r_i\le1$ .求最小正整数 $H$ ，使每个 $Hr_i$ 都是非负整数。未列出的作物可以占剩余比例。

每个比例由两个字符串表示：有限部分 $F$ 和循环部分 $P$ ，中间用一个空格分开。$F$ 由一个整数位、一个小数点和零个或多个小数位组成；$P$ 为非空数字串。$P$ 在 $F$ 后无限重复。例如 `0.7 142857` 表示 $0.7142857142857\ldots$ ，`0. 3` 表示 $1/3$ .循环部分全部为零时表示有限小数。允许前导零、重复多遍的循环节以及无限循环的 $9$ .

## 输入格式

第一行一个整数 $n$ .接下来 $n$ 行，每行两个字符串 $F,P$ .

## 输出格式

输出最小总产量 $H$ 的完整十进制表示，不取模，不使用科学计数法。

## 样例 1

### 输入

```text
3
0.3 00
0.15 00
0.5 0
```

### 输出

```text
20
```

## 样例 2

### 输入

```text
1
0.7 142857142857
```

### 输出

```text
7
```

## 样例 3

### 输入

```text
3
0.33 3
0.3 33333
0. 3
```

### 输出

```text
3
```

## 样例 4

### 输入

```text
2
0. 0
0. 9
```

### 输出

```text
1
```

## 样例解释

样例 1 的总产量取 $20$ 时，三种已知作物的产量分别为 $6,3,10$ ，剩余 $1$ 份可属于其他作物。样例 2 的比例为 $5/7$ .样例 3 的三种写法都表示 $1/3$ .样例 4 的两个比例为 $0$ 和 $1$ .

## 数据范围与保证

所有数据满足 $1\le n\le10$ .每行 $F$ 与 $P$ 的总字符数不超过 $200$ ，计入小数点，不计中间的空格。$F$ 的整数位为 `0` 或 `1` ，其余字符和 $P$ 均符合上述格式。

| 分值比例 | 额外条件 |
| --- | --- |
| 100% | 无额外条件 |
