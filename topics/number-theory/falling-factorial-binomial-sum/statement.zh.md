# 某不科学的下降阶乘与二项式求和

参考时间限制：0.5 秒；内存限制：128 MiB。实际时限取目标环境中最慢正式文件的标程中位耗时乘 2，再按 0.5 秒向上取整。见[评测环境](../../../docs/评测环境与性能.md)。

## 背景故事

小A在做学园都市第零次高中模拟考试试卷时，发现了一道有意思的数学题，于是他决定结合算法知识进行数据范围加强。

## 形式化问题描述

给定正整数 $n,k$ .定义下降阶乘

$$
i^{\underline{k}}=i(i-1)\cdots(i-k+1)
$$

当 $i<k$ 时，该乘积含零因子，因此值为零。计算

$$
\sum_{i=1}^{n}i^{\underline{k}}\binom ni\pmod P,\qquad P=10^9+7
$$

其中 $\binom ni$ 表示从 $n$ 个不同物品中选出 $i$ 个的方案数。物品的编号、展位的顺序都参与区分方案。

## 输入格式

一行两个整数 `n k` .

## 输出格式

输出一行，包含答案在 $[0,P-1]$ 内的余数。
## 样例 1

### 输入

```text
3 2
```

### 输出

```text
12
```


## 样例 2

### 输入

```text
2 3
```

### 输出

```text
0
```


## 样例 3

### 输入

```text
5 5
```

### 输出

```text
120
```


## 数据范围与保证

$1\le n,k\le10^9$ .特别地，$n<P$ ，但 $k$ 可以大于 $n$ .
