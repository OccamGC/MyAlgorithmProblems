# 抽奖插件 · 跳表

Codex（GPT-6）编写的 [C++17 实现](alternative-skip-list.cpp)按幸运值和编号定位前驱、后继。每个参与者复用自己的塔，初始有序数据按层尾接。塔高由固定种子产生并封顶，最坏一次查找仍可能是线性的。

前驱取值不超过目标的最后一个键，后继取值严格大于目标的第一个键，这也保留了题目的编号并列规则。塔高上限为 24，每次更新最多改 24 层链接，查找最坏 $O(n)$。固定层数下空间为 $O(n+q+k)$，其中 $q,k$ 为询问和修改数。
