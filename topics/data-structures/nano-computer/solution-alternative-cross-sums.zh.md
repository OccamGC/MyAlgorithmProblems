# 纳米电脑主机 · 维护跨界贡献的线段树

Codex（GPT-6）编写的 [C++17 实现](alternative-cross-sums.cpp)将答案拆为左段、右段和跨界子数组。左段的非空前缀计数先用空前缀替换整段前缀，再与整段异或，即得所有非空后缀；与右段非空前缀逐位统计异值对，恰好加入每个跨界子数组一次。空左段时替换净变化为零。

每个树结点记录各位的两类前缀计数和区间答案。设位数为 $B$，建树 $O(nB)$，单次操作 $O(B\log(n+1))$，空间 $O(nB)$。与主解相比，合并时即可得到完整答案，代价是更大的结点。
