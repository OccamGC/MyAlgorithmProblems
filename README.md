## 使用题目文件

`std.cpp` 是标准程序。另有实现时，`alternative.cpp` 或 `alternative-<method>.cpp` 及对应双语题解说明它的算法与适用范围；部分取舍方案不满足当前完整数据的时限，题解会明确标注。

先在本机以 C++17 编译程序，再在题目目录执行：

```text
python tests/generate.py --out-dir <输出目录> --std <已编译的标准程序路径>
```

省略 `--std` 时只生成输入；`--case <用例编号>` 可只生成指定用例。编号、参数与固定种子见 `tests/plan.json`。生成结果和可执行文件可放在题库的 `build/` 目录。带特殊评测的题目在题解中说明检查器用法。

参考时限与性能数据见[评测环境与性能](docs/评测环境与性能.md)。部署到其他评测环境时，重新测量标准程序的最慢用例中位耗时，乘以题面标注的倍率（默认 2），再按 0.5 秒向上取整。

在题库根目录运行 `python tools/check_statements.py`，可检查双语样例、数据分组、数学转义、文档链接与图片引用。
